# 双场景演示脚本

## 紫金山人像

1. `start.ps1` 启动后打开 `http://127.0.0.1:3800`。
2. 选“紫金山的光与影”，保留离线演示。确认 2026-10-03、14:00–19:00、35/85mm 两支镜头。
3. 生成，确认 Notebook，查看实际步骤 SSE。
4. 地图圆圈代表近似区域；没有入口数据就不展示虚假入口。
5. 任务卡分别使用 35/85mm。点“规则依据”，展示曝光为建议起点；点天气，展示 FIXTURE。
6. 点“天气变差”，展示字段 Diff，正式计划仍 V1。先拒绝演示不落库，再重新提出并批准为 V2。其余任务保持原样。
7. 点“撤销修改”，变为 V3，恢复初始任务。

## 南京夜景

1. 选“蓝调时刻的南京”，自动填入 16–35/70–200mm 与三脚架。
2. 生成计划；展示日落/蓝调为 Astral 实算，但天气为固定演示数据。
3. 指向被摄主体的虚线仅是区域方位示意，不是精确实测构图。
4. 查看 ISO 100、f/8、2 秒起点以及高光调整规则。
5. 点“开放有变化”，审批取消对应任务，再 Undo。
6. “证据与来源”区展示分类和获取时间；没有真实 URL 的离线示例不编造链接。

## 坐标与历史

选中区域 → “记录站位/入口” → 输入核对过的 WGS84 坐标 → 生成位置提案 → 审核字段 Diff → 批准。开放状态保持未知。“我的计划”从数据库重新载入，导出 JSON 保留证据和完整规则输出。

## CLI 离线复现

```powershell
.venv\Scripts\python demo/export_seeds.py
```

输出到 `demo/output/`。展示前必须说明合成数据的性质，不拿它作为出行当天的开放或天气建议。
