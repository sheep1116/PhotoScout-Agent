# 结构化拍摄建议与地图核验

日期：2026-09-12。本轮把 PhotoScout 的联网内容生成、产品展示与确定性核验拆成清晰的三层。

## 用户体验

用户描述拍摄目标后，可在确认页补齐目的地、日期、当地时间、主体、风格、光线、器材和推荐模式。手动选择始终优先于文本解析。

- **最佳机位**：联网顾问可以搜索和比较多个潜在机位，但在一个响应中只选出一个主推荐，并说明胜出理由。
- **多个候选**：联网顾问在一个响应中返回多个机位并给出全局排序。

结果页不直接展示长篇模型回答，也不出现供应商或模型名称。每个推荐机位用独立卡片展示时间、构图、焦段、参数、到达方式、注意事项和折叠来源；时间轴统一标出黄金时刻、日落、蓝调与推荐窗口。无法归入卡片的补充文本只在没有结构化候选时折叠显示。

## 数据流

`用户描述 → 可编辑 TripBrief → 结构化联网发现 → AgentAnswer/AgentCandidate → 高德锚点解析 → PhotoSpot → 天气/太阳/器材/空间几何 → ShotPlan → 机位卡片`

- `display_name` 只负责用户可读名称，`map_anchor` 专门用于高德检索，二者不要求相同。
- 每个候选具有一个 `camera_location` 和一个或多个 `subject_locations`；相机与每个主体分别解析。
- `AgentCandidate` 可以没有坐标；`PhotoSpot` 只保存可形成地图点的空间实体。
- 旧字段继续作为读取兼容层，但新请求明确要求位置锚点协议。
- 搜索来源只保留候选明确引用或实际证据使用的链接。

## 核验与地图

前端用自然标签展示状态：地图已定位、区域已定位、方向已核验、位置待确认。内部状态不会直接暴露给用户。

高德解析相机点和每个主体点后，PhotoScout 分别计算：

- 相机到每个主体的直线距离；
- 每个主体的方位角；
- 多主体的最小方位夹角；
- 推荐焦段的近似水平视角与平面同框判断。

地图绘制相机点、主体点及相机到主体的方向线。该结果不证明实际无遮挡，也不包含楼体高度、地形和三维遮挡，因此统一放入“出发前确认”。

## 参考样片

已关联到候选的公开社区来源可提供封面/预览图，优先作为“参考样片”展示，并保留平台、作者、原文链接和版权说明。目前对 Bilibili 使用公开元数据与受信图片 CDN；不绕过登录、验证码或平台限制，也不代理任意网页图片。高德地点图、Wikimedia 与 Flickr 附近图片继续作为降级参考，并明确它们不等于精确站位样片。

## 失败降级

- 有结构化建议但地图无法定位：保留机位卡与来源，显示“位置待确认”，不生成猜测坐标。
- 有地图点但来源标题不足：显示地图可定位但仍待来源核验。
- 图片服务不可用：保留文字建议与原始来源链接。
- 天气、开放、安全和光线不会从模型文本直接授信，仍由独立数据和规则核验。

## 验收覆盖

自动测试覆盖推荐模式进入请求、最佳机位采用显式主推荐而非第一项、手动选择优先、位置锚点兼容、多主体距离/方位/同框计算、社区参考样片归因、结构化结果页、折叠来源以及旧计划兼容。
