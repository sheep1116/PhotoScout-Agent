# 简洁提示与默认拍摄时间

2026-09-12

页面只在拍摄描述、城市定位和时间三个位置提供统一信息图标。支持悬停、键盘聚焦、点击查看；Escape、失焦或点击外部关闭。提示浮层不参与表单排版。自动定位使用输入框内的小标签，自动时间使用浅色值与“自动”标签。移除了搜索按钮下方的流程说明和候选列表上方的访问顺序说明；错误、风险及确认页必要信息仍保留。

默认时段按规划使用的 IANA 时区计算，精确到分钟：今天为当前时间至 23:59，未来日期为 00:00 至 23:59，默认结束日期等于拍摄日期。修改日期时只更新仍由系统生成的字段。手动输入或自然语言明确指定后，该字段不再被当成自动值；即使用户填的恰好也是 00:00 或 23:59，也不会被重新接管。

`frontend/lib/defaults.ts` 负责本地时区计算与字段更新；`auto_time_fields` 显式记录哪些时间字段仍是自动值。自然语言解析变更日期时，后端同步更新这些默认项，并保护人工修改项。旧记录未携带该标记时，保守地保留已有时间。原有当天/次日、时间先后及夏令时合法性校验继续生效；23:59 分钟内的当天默认起止相同，提交时仍会要求选择有效时段。

`frontend/components/FieldHint.tsx` 统一交互，样式在 `globals.css`。未给所有字段增加问号，也未改动候选发现架构。

验证：156 项后端测试通过；16 项页面/默认时间测试通过，另 1 项须指定已保存 Live 结果的测试本轮跳过。覆盖日期切换、分钟精度、规划时区与夏令时、自然语言/手动时间优先、自动标记、提示操作、移动端边界及布局稳定。本轮不需要新增真实 API 请求。
