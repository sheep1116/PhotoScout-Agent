# PhotoScout：自然语言与发现优先升级

日期：2026-09-11。此文说明本轮最终行为；较早升级报告保留作为历史记录。

## 现在怎样使用

打开页面后，地点、用户本地日期和时间自动给出灰色建议，不会自动搜索。先写一句话，例如“明天想在南京拍电影感的湖面倒影，不想走太远”，点击发现。确认页展示识别标签、原始描述和可修改的地点、日期、时段、摄影方向、主体、风格、光线与偏好。已经手动修改的项目优先保留，描述没提到的项目沿用当前值。

如果地点是“鼓楼”等歧义名称，确认页展示高德实际返回的选项，选择后才能继续。支持重新查询；没有匹配或服务失败时请补充城市重试。最终候选互相独立，没有“先去 A 再去 B”的行程顺序。

## 六项变化

1. **保留优秀但当前条件不佳的地点**：雨天、云多、光线时段不匹配、距离较远等降低匹配分并出现在候选卡醒目提醒中。雷暴、大风和危险线索保留为供之后参考的候选，同时明确不建议当前户外拍摄。关闭、已知开放时间不相交等强事实仍可排除。
2. **描述真正进入发现**：先用一次不联网搜索的千问调用提取条件，每个模型字段须带原文片段；规则补充明确词句。格式错误的单项不会抹掉其他有效需求，模型失败会明确告知降级。确认后的结构化意图与完整原文一起进入后续联网搜索。
3. **移除无效拍摄方式**：前端四种模式、后端 UserProfile、隐式 genre 及其分支已删除。实际器材仍参与参数建议。旧数据库 JSON 在读取入口迁移，不需要清空历史结果。
4. **偏好中性**：步行预算默认空，免费、人少、无台阶默认不选。普通偏好影响排序和说明。明确“只推荐免费”“必须无台阶”会记录严格意图，已知不满足才排除；信息未知会告知尚未核实。
5. **稳定地点确认**：DestinationLocation 保存高德 ID、POI ID（行政区记录可能没有）、Adcode、标准名、经纬度。前端不能把任意坐标当成已确认高德结果。服务端临时确认记录与提交信息逐项比对；后续检索采用标准名和行政代码，减少模糊字符串推断。
6. **摄影方向平等**：类别去重并固定排序，关键词包含所有方向，匹配评分平均各方向权重；没有点击顺序产生的主题。模型发现及推荐解释使用整组意图。

## 代码阅读顺序

| 文件 | 本轮职责 |
|---|---|
| `frontend/app/page.tsx` | 默认建议、描述入口、确认状态与候选风险展示 |
| `frontend/components/BriefConfirmation.tsx` | 编辑识别结果，处理地点选项，确认后生成 |
| `frontend/components/IntentBuilder.tsx` | 平等方向、组合画面条件和推荐偏好 |
| `backend/app/intent_parser.py` | 原文提取、证据片段校验、逐项格式验证、缓存、降级 |
| `backend/app/destinations.py` | 高德消歧、稳定记录和选择校验 |
| `backend/app/models.py` | PhotographyIntent、RecommendationPreferences、DestinationLocation、alerts；旧记录迁移 |
| `backend/app/providers.py` | 把原文与全部方向传入真实发现；使用已选地点信息核验候选 |
| `backend/app/engine.py` | 强事实门控、基础评分与真实器材建议 |
| `backend/app/recommendations.py` | 每个候选独立寻找可用窗口，软评分调整及风险提示 |
| `backend/app/changes.py` | 刷新天气后更新评分/提醒，沿用可审批变更机制 |

确认前的模型解析最多一次（30 秒超时，30 分钟缓存）；生成阶段仍最多两次联网检索。它们是两个不同阶段，旧生成 metrics 不包含确认前解析的令牌和耗时，不应把它当成整个交互总成本。模型不会收到 API Key；密钥只用于服务端认证。

## 仍有哪些限制

- 地点来源核验仍必需；放宽天气等条件不会绕过地理范围、来源真实性或接口调用上限。不保证总有多个候选。本轮真实样本保留了区域级线索，不应把区域中心当作精确相机站位；请查看结果中的关联等级和未知方向。
- 降权是可解释经验规则，没有训练或实地校准。“夕阳可见机会较低”是定性提示，不是天气服务提供的日落可见概率。
- 实际步行、实时客流、台阶和票务覆盖仍不足。当前距离为定位起点到机位的直线距离，不能冒充步行公里数。严格步行/人少意图会记录，但缺少可靠数据时无法保证达成；卡片会提醒核实。
- 歧义选项依赖高德实际返回，最多展示 10 项，不是全国同名地点的完整清单。确认记录默认内存保存一小时，重启/过期后新搜索需要重新确认；已保存结果仍可读取。
- 模型原文引用只说明提取依据，仍可能误解否定、复杂日期或风格，确认步骤不可省略。规则降级覆盖有限；可在确认页修正。照片无可用来源时正常降级。
- Wikimedia/Flickr 等外部来源仍依赖网络和配置；社区仅作为发现线索。本轮不含公网部署、认证、账号隔离或生产队列改造。
