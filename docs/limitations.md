# 已知限制与验收范围

这是完成 0.2 产品功能升级的本地摄影工作台，以下边界没有隐藏在“已完成”表述中。

1. **Live 验收范围有限**：2026-09-09 经用户授权使用已配置账户，完成南京人像真实搜索、高德、天气、计划生成、审批、撤销和重启读取，24 项验收检查通过，见 [报告](live-acceptance.md)。这不代表其他账户、所有城市/题材或入口间路线均已验收。健康接口的“已配置”仍不等同于当前调用必然成功。
2. **官方开放复核保持保守**：已实现来源等级、时效、冲突规则。新增的标题地域/地点相关性筛选可排除通用教程，但不是全文逐句核验，部分真实搜索来源本轮无法打开原文。搜索抽取的 Claim 仍是线索，不自动授予当日开放、商业拍摄或安全许可；暂未提供各景区逐一核验的官方运营数据接入。任务标记暂定。
3. **不是通用自然语言代理**：基础中文解析覆盖南京题材和 ISO 日期；日期、时间、镜头、预算等通过表单确认。相对日期不猜测；复杂自然语言约束需要在表单表达。
4. **路线**：离线路线为合成数据。Live 无确认入口时使用单点拍摄序列。用户可以记录入口并审批，但当前没有自动把确认后的入口重新做多点路线优化的 UI。步行 Provider 可用于后续扩展。
5. **地图**：离线区域图是示意；MapLibre 在线图需网络和 WebGL。区域中心不能当精确导航终点；转换误差不适合测绘。
6. **改计划**：天气刷新按材料阈值产生提案；默认安全备选是取消该段/停止户外，未实现自动寻找并核验室内地点。不会虚构替代点的可达性。
7. **评分**：权重和置信度是可解释启发式，尚未做现场样本校准。当前排程为有缓冲的贪心序列，不是全球最优路线，也不保证总有 3–5 个任务；条件不足可更少或为空。
8. **基础设施**：本地 SQLite 与 Compose/PostgreSQL/PostGIS/Redis 已跑通，容器版 6 项 E2E 通过。SQLAlchemy 初始化表，PostGIS 另有幂等 SQL 迁移。正式生产仍需要 Alembic、备份与迁移管理。
9. **单用户与单进程**：API 无认证；进度任务队列在内存，不支持多 worker/分布式恢复。已保存计划不会丢；进行中的任务重启后需重新提交。
10. **评测解释**：Schema 和 Evidence 指标检查结构和引用，不衡量网页内容是否真实；注入用例检验受限处理路径，不是全面红队审计。Fixture 测试 0 API 成本，Live 成本不估算为 0。
11. **器材**：APS-C 默认 1.5×；Canon APS-C 等其他系数尚无单独选项。手机光圈固定，数字只是示例起点，应按设备自动曝光规则操作。
12. **第三方权利**：未抓取需要登录的社区、未绕过付费墙；新增代理按需传输真实公开参考照片，不批量归档。在线底图和 Provider 需遵守第三方条款，参见 THIRD_PARTY_NOTICES。


## 2026-09-10 升级验收补充

四项产品功能已交付，详见 [升级说明](product-upgrade.md)。119 项后端测试、8 项 E2E、62 条离线评测、14 项 Live 检查通过。新增真实参考图、独立机位地标、组合式意图和可扩展图片 Provider。

- Wikimedia 在当前机器连接超时；Flickr 缺少 Key。模拟契约通过不等于实际账户联网验收；页面会报告跳过/不可用。
- 图片优先高德，其次通过附近坐标丰富。附近图可能拍的是相邻主体，必须显示关联等级，不能宣称该精确机位样片。拍摄时间、EXIF 和授权缺失时不补造。
- 社区发现依赖公开搜索结果，不保证命中每个平台；仍未实现平台直接授权 API、原帖全文核验或自动近期状态确认。
- `mapped_viewpoint` 表示地标关系匹配，仍为 MAP_POINT；不是实测相机位置。大范围候选保留 AREA，未知方向留空。
- 无台阶要求没有可达证据时可能生成空计划；光线偏好超出用户时段会明确提示，绝不擅自扩展出行时间。
- 本次未重新验收 Docker 数据库环境，也未部署公网；默认启动器使用本地进程。公网运营仍需认证、用户隔离、配额、队列与备份，不能直接公开无认证 API。
